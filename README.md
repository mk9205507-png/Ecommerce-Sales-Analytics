E-commerce Sales Analytics Dashboard

Project Overview

The E-commerce Sales Analytics project focuses on analyzing e-commerce sales data to identify sales trends, understand customer segments, evaluate product performance, and generate meaningful business insights.

The project uses Python Pandas for data cleaning and analysis, Matplotlib for data visualization, and Microsoft Power BI to build an interactive dashboard for business reporting and decision-making.

Objectives

- Clean and prepare raw e-commerce sales data.
- Identify sales and profit trends.
- Analyze product and category performance.
- Understand customer segment distribution.
- Explore the relationship between sales, profit, and other business metrics.
- Build an interactive Power BI dashboard to support data-driven decisions.

Tools and Technologies

- Python – Data analysis
- Pandas – Data cleaning, transformation, and analysis
- Matplotlib – Exploratory data visualization
- Microsoft Power BI – Interactive dashboard development
- Jupyter Notebook – Python development environment

Project Workflow

1. Data Cleaning Using Pandas

- Loaded the raw dataset into a Pandas DataFrame.
- Checked column names and data types.
- Identified and handled missing values in the Rating and Customer Segments columns.
- Checked for duplicate records.
- Prepared the cleaned dataset for further analysis.

2. Data Analysis

Used Pandas to explore the dataset and analyze sales-related information, product performance, customer segments, and business trends.

3. Data Visualization Using Matplotlib

Created visualizations to explore patterns and trends in the dataset and support the analysis.

4. Power BI Dashboard

Imported the cleaned dataset into Power BI and created an interactive dashboard featuring relevant business metrics, charts, and slicers to explore the data from different perspectives.
